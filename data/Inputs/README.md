# Evaluation source documents

The extraction pipeline was evaluated using four technical and research
documents. Only the CC BY 4.0 paper is included in this public repository.

| Source used in the evaluation | Availability in this repository |
| --- | --- |
| Bendechache et al., *A Systematic Survey of Data Value: Models, Metrics, Applications and Research Challenges*, [DOI](https://doi.org/10.1109/ACCESS.2023.3315588) | Included under CC BY 4.0 |
| Radulovic et al., *A Comprehensive Quality Model for Linked Data*, [DOI](https://doi.org/10.3233/SW-170267) | Not redistributed; obtain from the publisher or an authorised repository |
| Zaveri et al., *Quality Assessment for Linked Data: A Survey*, [DOI](https://doi.org/10.3233/SW-150175) | Not redistributed; obtain from the publisher or an authorised repository |
| Draft ETSI DATA document used during the project | Not redistributed |

The derived CSV files, manually constructed gold standard, match analysis, and
generated RDF outputs remain available elsewhere in this repository.
